# Web Development Tasks 2, 3 and 4

## Task 2 - Calculator
Open `Task_2_Calculator/index.html` in a browser.
- +, -, ×, ÷ and %
- Clear and delete
- Real-time display
- Keyboard support

## Task 3 - Portfolio
Open `Task_3_Portfolio/index.html`.
The portfolio is responsive and includes About, Skills, Projects and Contact sections.
Replace the placeholder email/social links before publishing.

## Task 4 - Music Player
Open `Task_4_Music_Player/index.html`.
It includes play/pause, previous/next, progress bar, volume, playlist and optional autoplay.
The demo uses public SoundHelix MP3 URLs, so internet access is needed for the demo tracks.
You can replace the URLs in `script.js` with your own audio files.

## Suggested submission
Submit the three folders separately if your internship/college portal asks for individual tasks.
